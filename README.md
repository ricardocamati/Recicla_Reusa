# Recicla/Reusa

PoC acadêmica alinhada ao **ODS 12 — Consumo e Produção Responsáveis**.

Este primeiro commit prepara somente a estrutura inicial do projeto:

- Python 3.11+;
- FastAPI e MongoDB planejados;
- configuração de dependências;
- variáveis de ambiente de exemplo;
- pasta `frontend/` reservada para um cliente web separado.

As funcionalidades serão adicionadas em branches e integradas progressivamente à `main`.
